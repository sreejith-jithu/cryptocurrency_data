🚀 Live Cryptocurrency Data Fetcher & Analyzer
This Python script fetches live cryptocurrency data for the top 50 cryptocurrencies from the CoinGecko API and updates an Excel sheet (crypto_data.xlsx) every 5 minutes with the latest prices, market caps, and other key metrics.

📌 Features
✅ Fetches live data for the top 50 cryptocurrencies
✅ Performs basic analysis, including:

Top 5 cryptocurrencies by market cap
Average price of the top 50 cryptocurrencies
Highest & lowest 24-hour price change percentages
✅ Automatically refreshes every 5 minutes
✅ Saves data to an Excel file (crypto_data.xlsx)
✅ Creates formatted & structured sheets in Excel


📊 Excel Output
The script automatically generates an Excel file (crypto_data.xlsx) with:

Crypto Data Sheet: Live prices, market caps, volume, and percentage changes
Analysis Sheet: Insights on top 5 cryptos, average price, and highest/lowest 24h changes
📌 Note: The Excel file refreshes every 5 minutes. Leave the script running to keep updating the data.


API Used
CoinGecko API
